This SOP lists every tag the Closing Table OS puts on a contact, what each one means, and exactly how to build automations on them.

1Know the tag families

Every tag starts with where it came from. The app adds and removes them for you. You never add these by hand.

2Know where the tags come from

The OS sends each signup and deal to one Zap, and the Zap tags the contact in GHL.

Zapier → Zaps → 01 - OS → Closing Table OS → GoHighLevel (contacts + tags)

"One at a time" tags (stage, cal-fund, cal-cash, cal-exp) swap automatically. If someone answers differently next time, the old tag comes off and the new one goes on.

⚠️ Never add tags with Zapier's GoHighLevel app ("LeadConnector" → Add/Update Contact). Its Tags box replaces every tag the contact already has, including paid course tags. The OS Zap uses a safe method. Copy it if you ever need another tag Zap.

3Build an automation on a tag

  1. Automation → Workflows → + Create Workflow → Start from Scratch
  2. Click the name at the top and rename it, e.g. Closing Table OS – Hard Money Nurture.
  3. Add New Trigger → Contact Tag → Add filters → Tag Added → pick the tag
  4. Add your actions (Send Email, Add to Workflow, Wait until a specific date/time).
  5. Top right: switch Draft → Publish → Save.
⚠️ Workflows only catch tags added after you publish. Publish before you announce or promote anything, or early people never enter it.
♻️ Next automation: duplicate a working workflow and swap only the trigger tag + the email.

4Pull a list of people by tag

Contacts → Smart Lists → + Add filter → Tags → Is → pick the tag → Save as Smart List

Examples:

  • All OS users: closing-table-os:signed-up
  • Hard money buyers with real cash: cal-fund:hard-money + cal-cash:50-100k
  • First-timers who ran a deal: cal-exp:new + tool:max-offer-used

5The three email workflows

A and B are live. C still needs to be built, with the exact email in HANDOFF/CALCULATOR-SIGNUP-ENDPOINT.md. Publish C before the website calculator goes live.

WorkflowTrigger tagSends

B · Closing Table OS – Reset Passwordclosing-table-os:reset-passwordReset-password link
C · Closing Table OS – Login Linkclosing-table-os:login-link"Your deal is saved" sign-in link for people who already have an account

Each one: Send Email (button link = {{contact.contact_closing_table_os_action_link}}) → Remove the same tag → Allow Re-entry ON.

Build once. Never delete or rename these three, or people stop getting their sign-in emails.

6Adding a new tag later

New tags come from the app, so ask Gio (or Claude). Naming rules:

  • Start with where it comes from: cal- calculator answers, tool: tool used, stage: investor level, closing-table-os: account events.
  • All lowercase, dashes between words, one colon between the group and the value.
  • Keep it short: cal-fund:hard-money, not calculator-funding-type:hard-money-lender.
♻️ Next tool (Funding Path Finder, First Deal Blueprint): the delta is one new tool:<name>-used tag plus that tool's answer tags with their own short prefix. Everything else stays the same.

7Test it (do this after any change)

  1. Go to app.henrywashington.com, sign in with your own email, and run one deal in the Max Offer Calculator.
  2. Zapier → Zap History → newest run of the OS Zap shows Successful (or Filtered, which is also fine).
  3. GoHighLevel → Contacts → search your email → Tags
  4. Check you see tool:max-offer-used, one stage: tag, and one each of cal-fund:, cal-cash:, cal-exp:.
  5. Check your old tags are still there. If any old tag disappeared, stop and tell Gio right away.
